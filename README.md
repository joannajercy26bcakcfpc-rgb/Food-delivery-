# Food Delivery App – Project Documentation

## 1. Project Overview

The food delivery app allows users to order their favourite food online from nearby restaurants. It provides a simple and convenient way to browse menus, place orders, and get food delivered to their doorstep.

## 2. Objective

The main objective is to make food ordering easy, fast, and convenient for users. The app aims to provide a smooth ordering experience with secure payments and timely delivery.

## 3. Design Highlights

 Attractive colours and a clean, modern UI.
Simple navigation with food categories and search options.
 Clear food images, cards, and readable text.
 User-friendly buttons and an easy checkout process.

## 4. Features

 User Login: Sign up and log in securely.
Food Categories: Browse different types of food.
 Search Food: Find favourite dishes quickly.
 Cart: Add, remove, and manage food items.
 Online Payment: Pay using available digital payment methods.
 Order Tracking: Track order status and delivery progress.
 Order History: View previous orders.
